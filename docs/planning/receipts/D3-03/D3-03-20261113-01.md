Changes are uncommitted. D3-01 is present in the merged base; its parser
validates provenance records but does not calculate hashes or derive staleness.

The selection component offers explicitly synthetic areas and requires a
rationale. The local-service functions retain the selected geometry and
feature revision, project revision, rationale, method record, and SHA-256
hashes of recursively key-sorted JSON. Array order is preserved. Saving uses a
new file per request and reopening checks the stored hashes against the current
method. Changing area identity, geometry, project revision, or method clears
derived inputs: those inputs describe the previous selection and cannot safely
be reused for a different one.

This is a synthetic mechanism, not an integrated research screen or job. The
component and persistence functions are not connected to the diagnostic app or
an HTTP endpoint. The caller must supply the current method and a destination
within the project storage workflow, which does not yet exist here. Polygon
topology is not validated by this slice. Real geography is rejected; D3-17
requires the D2-12-reviewed walkshed for the actual Maple population claim.
