## Proposed rendering contract update

The bridge adapter accepts a DOM container, a same-origin style and font
resource mapping with stable IDs, an explicit frame viewport, and optional
initialization and frame deadlines. Both defaults are 30 seconds. A host
sets MapLibre's worker URL to the locally served pinned
`maplibre-gl/dist/maplibre-gl-worker.mjs` before mounting. The adapter
imports the pinned MapLibre CSS. Hosts supply the same pinned asset bytes
to both surfaces. This fixture maps assets to local HTTP URLs and embeds
its GeoJSON inside the style. The service-side manifest mapping and
additional resource types remain separate work.

The surface starts initialization on its first frame request. It loads and
decodes the explicit font file, registers its own `FontFace`, and mounts a
static Mercator style with zero style and symbol transitions. The bridge
style supports background, fill, line, and circle layers with inline
GeoJSON. It disables interaction and automatic resize, requests a
preserved drawing buffer, and fixes the map and SVG at the requested
dimensions and pixel ratio 1. A variant size change needs a remount.
Show the fixed-size surface before requesting a frame. A request fails with
`viewport` if the map layout, canvas, or drawing buffer cannot provide the
requested dimensions. When layout returns to its fixed size, the host can
request the frame again. An outer host can scale the fixed-size surface
for display.

The host passes a unique request ID to each `applyFrame(frameState, requestId)`
call. The adapter hides the previous content, replaces the projected SVG
content, and waits for a MapLibre render after
the mutation and then an idle event with a loaded map and ready tiles.
The adapter requests a repaint even when the camera is unchanged. A
successful call resolves with its own request ID and frame. A newer request
rejects the previous pending request as superseded. The host inspects the
pending resource IDs or the error and uses `dispose()` to remove the map,
SVG, and font when the surface ends. The React host owns Remotion delay
handles and serial frame capture.

A request fails with `camera` when MapLibre's applied center, zoom, bearing,
or pitch differs from the requested state. The comparison accounts for
longitude and bearing wrap and allows a numerical tolerance of 0.000000001
in degrees or zoom units. The error includes the requested and applied values.

A lost context, map error, missing style or font, or exceeded deadline
leaves the surface hidden and returns an actionable failed-frame error.
The adapter implements one MapLibre rendering mode. If the bridge cannot
capture MapLibre, the documented static draft fallback requires a
permitted, geographically registered image and valid projected overlays.
The draft must declare its mode and leaves the moving MapLibre gate open.
