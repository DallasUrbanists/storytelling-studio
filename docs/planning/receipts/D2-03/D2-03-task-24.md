## Implemented API and behavior

The camera module exports `cameraExtentForGeometry`, `fitCameraToExtent`,
`fitFocusStep`, `cameraFitLimits`, `CameraFitError` and their TypeScript types.
The helpers are available from `packages/story-core/src/camera.ts`; the shared
package index was not changed under this reservation.

`cameraExtentForGeometry` computes detached WGS84 bounds for supported Point,
LineString and Polygon geometry, including polygon holes. The helper checks
coordinate shape, explicit ring closure and antimeridian segments; it does not
validate polygon topology, establish provenance or approve source geography.
Callers must use verified source geometry and retain its revision unchanged.

`fitCameraToExtent(extent, viewport, options)` fits ordered, nonwrapping WGS84
bounds in flat Web Mercator with `bearing: 0` and `pitch: 0`. Safe-area insets
and author padding add in output pixels at pixel ratio 1; omitted edges are
zero. Padding accepts one number or individual `top`, `right`, `bottom` and
`left` values. Each fit uses the largest zoom permitted by both available axes
and the zoom cap, and centers the projected bounds in the resulting safe area.
Asymmetric insets shift the camera center; latitude uses a Mercator midpoint.

Zero-width or zero-height extents constrain only their nonzero axis. Point and
fully collapsed bounds use `maxZoom`, which defaults to 22 and can be set within
the bridge's [-2, 22] range. Tiny extents cap at that zoom without expanding or
changing source coordinates. A collapsed polygon's bounds can be framed, but
this behavior does not certify that polygon as valid source geometry.

`fitFocusStep(step, outputVariants, optionsByVariant)` takes a validated step
and returns a detached copy with complete saved portrait and landscape
overrides. Each output independently fits its override extent, or the shared
step extent when absent. Existing camera overrides are explicit manual framing
and are retained; removing a variant's camera override requests a new automatic
fit for that output. The helper preserves the base extent, fallback camera,
timing, transition, IDs and source references. It does not mutate project data.

Manual framing bypasses automatic containment and padding, so the author must
review its landmark coverage. Manual cameras must still satisfy finite camera,
flat-ground and bridge constraints. Automatic fits guarantee containment of
the supplied bounds at the saved target, not every intermediate frame of a
camera transition. Evaluation and export continue to use saved cameras without
hidden refitting; no editor control or new persistence field is introduced.

`CameraFitError.code` distinguishes malformed extents, geometry, viewport,
padding, zoom caps and manual cameras from `unsupported-bounds`. Unsupported
inputs include antimeridian wrapping, coordinates beyond longitude ±180 or
latitude ±85.05112878, and fits whose viewport exceeds the Mercator world.
The camera guard conservatively includes screen height and rotated manual
viewport corners, preventing silent MapLibre constraint changes. A fit fails
atomically without clamping bounds or changing the original step. Arbitrary
rotated automatic fitting, terrain and perspective remain unsupported.
