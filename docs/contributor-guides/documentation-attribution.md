## Changes in this adaptation

The Storytelling Studio version carries a prominent modification notice and
retains the Apache-2.0 terms for its Idea Map-derived material and additions.
The upstream Creative Commons attribution notices continue to apply to their
respective borrowed material.

The adaptation changes the following rules and examples:

- Authors must distinguish planned requirements from working software; the
  upstream present-tense rule does not apply here.
- Authors must keep unverified facts, derived estimates, editorial
  interpretations, and assumptions distinct.
- Contributors use Windows-first guidance and npm once verified scripts exist;
  the upstream pnpm service example is removed.
- Authors use Storytelling Studio terminology, its glossary, and its planning
  and implementation-status records.
- Documentation review can record direct file inspection when no Git worktree
  exists, instead of claiming an unavailable Git check passed.
